# 🎤 TechCon Conference Website

A five-page static website for a fictional tech conference, built with semantic HTML for the **ALX Front-End** programme.

![HTML5](https://img.shields.io/badge/HTML5-E34F26?style=flat-square&logo=html5&logoColor=white)

## Pages

| Page | Contents |
| --- | --- |
| [`index.html`](index.html) | Home page with the conference overview |
| [`about.html`](about.html) | About the event |
| [`schedule.html`](schedule.html) | Talks and sessions in a table |
| [`register.html`](register.html) | Registration form |
| [`contact.html`](contact.html) | Contact form |

## What I practised

Semantic HTML5 elements (`header`, `nav`, `main`, `section`, `footer`), navigation links between pages, tables and forms.

## Run it

```bash
git clone https://github.com/Dwaynemaster007/TechCon_HTML.git
cd TechCon_HTML
# open index.html in your browser
```
